# Research: The Language of Automation

**Bash Script**
A text file containing a series of shell commands executed by the GNU Bourne-Again SHell. The shebang line (#!/bin/bash) at the top tells the operating system which interpreter should be used to parse and execute the script.

**Variables**
Placeholders (such as \$BACKUP_DIR) used to store dynamic data or file paths, allowing scripts to remain flexible, readable, and easy to maintain without hardcoding values repeatedly.

**Cron Job**
A time-based job scheduler in Linux-like operating systems that executes scripts or commands automatically at specified dates and times, making it essential for routine cloud maintenance like backups.
