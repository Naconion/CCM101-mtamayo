# Mission Reflection

Reflecting on this activity, I believe compute resources are the most fundamental building block of any cloud system. While storage keeps our data persistent, networking enables communication, and IAM secures access, compute power acts as the main engine that actually executes application logic and processes user requests[cite: 1]. Without compute capability, none of the other components have active work to support[cite: 1]. 

Underneath almost all of these cloud environments, Linux plays a massive role[cite: 1]. It serves as the backbone of modern cloud computing because it is lightweight, open-source, highly secure, and incredibly efficient at managing hardware resources[cite: 1]. Working directly with the Linux CLI showed me how seamlessly cloud platforms rely on the Linux kernel to run containers, handle virtualization, and execute administrative commands with minimal overhead[cite: 1].

This lab also taught me that thorough technical documentation is just as critical as writing code or launching servers[cite: 1]. Planning and documenting infrastructure before deployment helps teams catch design mistakes early, track resource dependencies, and estimate operational costs accurately[cite: 1]. It provides a clear blueprint for the entire team, making future troubleshooting and onboarding far easier[cite: 1]. 

Throughout this mission, I gained practical hands-on experience using Linux CLI tools like `lscpu`, `free`, `df`, and `ip a` to audit live server specs[cite: 1]. I also learned how to translate raw hardware data into cloud architecture concepts, map equivalent infrastructure services across AWS, Azure, and GCP, and turn system designs into visual diagrams[cite: 1]. Adding these detailed reports and structured commit histories to my GitHub portfolio makes my profile look much more professional[cite: 1]. It demonstrates that I can not only navigate cloud environments but also document design choices and follow real-world engineering workflows[cite: 1].
