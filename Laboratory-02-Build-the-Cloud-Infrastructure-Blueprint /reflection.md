# Mission Reflection

1. **Which cloud infrastructure component do you think is the most important? Why?**
   Out of all the core components, I consider compute resources to be the most critical. While storage keeps our data persistent, networking connects services together, and IAM manages security permissions, compute serves as the central engine that processes logic and handles user requests[cite: 1]. Without active compute capabilities, none of the other supporting cloud resources have an environment to run workloads or serve actual applications[cite: 1].

2. **How does Linux support cloud computing?**
   Linux serves as the foundational backbone for modern cloud computing because it is lightweight, open-source, highly secure, and exceptionally efficient at resource management[cite: 1]. Cloud providers rely heavily on the Linux kernel to run virtual machines, manage containerized environments, and handle system virtualization with minimal performance overhead[cite: 1]. Its powerful command-line interface makes remote automation and infrastructure scaling seamless for engineers[cite: 1].

3. **Why is technical documentation important before deploying infrastructure?**
   Preparing thorough technical documentation prior to deployment prevents costly architectural mistakes and keeps the entire team aligned[cite: 1]. It allows engineers to map out dependencies, justify hardware specifications, enforce security compliance, and estimate operational costs before launching live resources[cite: 1]. Having a well-documented blueprint also simplifies future troubleshooting, maintenance, and team onboarding[cite: 1].

I also learned how to translate system specs into cloud components, map equivalent core services across AWS, Azure, and GCP, and build clear visual architecture diagrams using modern diagramming tools[cite: 1].
