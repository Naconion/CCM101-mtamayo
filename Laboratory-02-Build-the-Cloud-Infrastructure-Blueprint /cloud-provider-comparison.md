# Core Cloud Provider Comparison

## Infrastructure Services Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 / EBS | Azure Blob Storage / Disk Storage | Cloud Storage / Persistent Disk |
| **Networking** | Amazon VPC | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS IAM | Microsoft Entra ID | Cloud IAM |

## Guide Questions & Analysis

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest range of services because it was the earliest pioneer in public cloud infrastructure and maintains the largest global market footprint with extensive service depth across compute, analytics, and IoT.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is the best recommendation for organizations heavily using Microsoft products due to seamless native integration with Windows Server, Active Directory, Office 365, and existing enterprise licensing agreements.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized for AI, ML, and Kubernetes services because Google originally developed Kubernetes and leads in specialized AI infrastructure like Tensor Processing Units (TPUs) and Vertex AI.

### 4. What similarities did you observe among the three cloud providers?
All three cloud providers offer core virtualized infrastructure abstractions (Compute, Storage, Networking, and IAM) under flexible, pay-as-you-go pricing models. Additionally, they each implement robust security frameworks and automated scaling controls across global data centers.
