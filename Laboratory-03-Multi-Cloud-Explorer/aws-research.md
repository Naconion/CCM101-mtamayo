# Amazon Web Services (AWS)
## Brief Overview
Amazon Web Services (AWS) official website is a comprehensive cloud computing platform that provides infrastructure and managed services for computing, storage, databases, networking, analytics, artificial intelligence, security, application development, and more. AWS is designed to let organizations provision resources on demand rather than maintaining equivalent physical infrastructure themselves. AWS describes its enterprise platform as helping organizations accelerate innovation, reduce costs, and scale efficiently. 


## Global Infrastructure
AWS organizes its infrastructure primarily into Regions and Availability Zones (AZs). According to AWS's current infrastructure page, AWS has 39 geographic Regions and 124 Availability Zones, with additional infrastructure announced. AWS also provides edge infrastructure and services such as CloudFront, Local Zones, Outposts, and Wavelength for workloads requiring lower latency or specific deployment locations. 


This architecture allows enterprises to distribute applications across physically separated Availability Zones and Regions to improve resilience, availability, and disaster recovery.

## Cloud Management Console
The AWS Management Console is a web-based interface that provides centralized access to AWS services. It allows users to search for services, manage resources, view notifications, access billing information, use AWS CloudShell, and customize the console dashboard. Each AWS service also has its own individual service console.

## Four Core Services
1. Amazon EC2 (Elastic Compute Cloud) – Provides scalable virtual servers in the AWS Cloud. Organizations can select different CPU, memory, storage, and networking configurations and scale capacity according to demand. 

2. Amazon S3 (Simple Storage Service) – An object-storage service designed for storing and protecting large amounts of data. Common uses include data lakes, websites, backups, archives, enterprise applications, and analytics. 

3. Amazon RDS (Relational Database Service) – A managed relational database service supporting engines such as PostgreSQL, MySQL, MariaDB, Oracle, SQL Server, Db2, and Aurora. AWS handles common administration tasks such as backups and database software maintenance. 

4. AWS Lambda – A serverless computing service that executes code without requiring customers to provision or manage servers. It automatically handles infrastructure, scaling, and patching. 

## Three Advantages
1. Extensive global infrastructure: AWS provides a large worldwide footprint of Regions, Availability Zones, and edge locations, allowing organizations to deploy applications close to users and design for resilience. 

2. Broad service portfolio: AWS offers services covering compute, storage, databases, networking, analytics, AI/ML, security, IoT, developer tools, and enterprise applications. 

3. Scalability and operational flexibility: Services such as EC2 and Lambda allow organizations to increase or decrease resources according to workload requirements rather than maintaining fixed physical capacity.
