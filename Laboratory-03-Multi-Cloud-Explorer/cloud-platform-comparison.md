# Synthesis Questions 

## Answer each question in 2–3 sentences:

**1. Which cloud provider offers the broadest range of services?** AWS offers the most expansive suite of services due to its first-mover status and continuous expansion.

**2. Which provider best integrates with Microsoft technologies?** Azure natively integrates with Active Directory, Windows Server, and Office 365 environments.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?** GCP leads due to Google's development of Kubernetes and advanced TensorFlow/AI tooling.

**4.  Which cloud platform would you personally choose and why?** Choose based on your primary skill set (e.g., AWS for overall versatility or Azure for enterprise administration).
