# Container Lifecycle

## A Cloud-Native Engineer must know how to manage running containers. Execute the following commands and observe the output.

**docker ps** = List running containers

**docker stop nginx-server** = Stop the running container

**docker ps** = List running containers

**docker ps -a**  = Verify it is stopped

**docker rm nginx-server** = Remove the container completely

**docker ps -a** = Verify it is stopped
